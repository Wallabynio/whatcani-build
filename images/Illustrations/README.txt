11 drawings, each in two colourways:
  <name>.svg          for light grounds (paper, stone, sky): ink line, stone fill
  <name>-on-ink.svg   for the dark ink ground: paper line, charcoal fill

layer-1..5   The five layers of "What can I build?" (How we work page)
menu-*       Drawings for the menu items (Services uses layer-1, How we work uses layer-5)

Style rules:
- One even ink line, rounded ends and corners (stroke 7 on a 240 x 240 drawing).
- Each main outline is left open at one corner, borrowed from the dwelling drawings.
- Flat stone shape behind, set 7 units down and to the right. No shading or gradients.
- One orange (#FF7700) detail per drawing. Never orange text.
- Lettering ("FSR", "$") is Inter Tight ExtraBold converted to outlines, so the files
  look the same everywhere without the font installed.
